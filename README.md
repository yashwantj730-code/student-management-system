# Student Management System

A full stack Student Management System by **Yashwant Jaiswal**.

**Tech:** React.js, Tailwind CSS, HTML, JavaScript, Node.js, Express

## Features
- Dashboard stats: total students, average attendance, average marks, low-attendance count
- Students-by-course chart
- Add, edit, delete students (with validation)
- Search by name / roll no. / email, filter by course, sort by name / marks / attendance
- Auto grade (A+ to F) and attendance bars
- Export to CSV
- REST API: GET/POST /api/students, GET/PUT/DELETE /api/students/:id, GET /api/stats, GET /api/health

## Run locally
    npm install
    npm run build
    npm start        # http://localhost:5000

## Deploy (Render)
Web Service · Build: npm install && npm run build · Start: npm start
